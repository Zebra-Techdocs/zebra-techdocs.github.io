TrustAll Creates a configuration that accepts all TLS certificates without validation.

This mode is intended for testing purposes only and should not be used in production environments.

TrustOSLevelKeyStore Creates a configuration that uses the operating system's trusted root certificate store for certificate validation.

On Windows, this corresponds to the Windows Certificate Store.
