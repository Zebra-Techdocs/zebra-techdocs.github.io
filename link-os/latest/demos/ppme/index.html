Overview

This public demo uses a customized[1] cloud hosted edition of Printer Profile Manager Enterprise (PPME) to enable you to connect your own printer and experience our comprehensive Print DNA printer management application.

[1] Some admin features have been removed due to this being a public demo.
Some product features such as discovery, accessing the printer webpages and the Weblink tab cannot function due to this being hosted in the cloud.

End of Sale has been announced for Printer Profile Manager Enterprise. Zebra Nucleus is the replacement product.

Important information

The hosted demo is open and available for anyone to use. This means any user can interact with, and/or send profiles/resources to any connected printers from the PPME console.

Zebra recommends disconnecting your printer(s) from the demo immediately after using it which can be done using the Remove Printer option from within PPME or using the configuration removal file below.

The hosted demo should not be used for production purposes and Zebra reserves the right to remove anything from the system, including but not limited to, printers, profiles, resources, and other configuration items.

Requirements

  • Chrome versions in Google’s stable release channel.
  • Either of the following:
    • Label/Receipt printer Link-OS v5.0 or later.
    • Card printer running Link-OS v1.0 or later.
  • Internet connectivity.
  • Printer configuration files from the sections below.

How do I connect my printer to the demo?

  1. Connect your own Print DNA printer to this PPME demo by downloading the printer configuration file from the section below and sending it to your printer.
  2. Connect your printer to a network that has internet access.
  3. To return your printer to normal operation, download the printer configuration removal file and send it to your printer.

For Card printers, the configuration files must be sent via port 9200.
